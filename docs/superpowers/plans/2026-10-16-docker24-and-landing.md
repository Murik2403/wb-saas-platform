# Docker 24 GiB, восстановление и соответствие лендинга

**Goal:** проверить 20/25/30 кабинетов и восстановление в локальном Linux Docker; исправить расхождения публичных обещаний с кодом.
**Architecture:** отдельный daemon без production socket, сети и секретов; зафиксированные исходники и образы, отдельные акты каждого размера. Лендинг правится локально без выкладки.
**Tech Stack:** Docker Desktop/WSL2, DinD, Python, pytest, Jinja, Chromium.
**Spec:** прямое поручение владельца 16.10.2026: Docker 24 ГБ после Claude; production не трогать.

## Ограничения

- Не обращаться к production SSH/API, не менять DNS, production конфигурацию и контейнеры.
- Сохранить оригинальную .wslconfig, неизвестные архивы и все отрицательные акты.
- Проверить a346358 независимо; не считать тесты доказательством нагрузки.
- Не понижать admission, порог памяти и критерии ради PASS.
- Docker восстановление не подтверждает новую ОС, ACME и reboot хоста.
- Сохранить три расчётных кейса и Telegram; не добавлять публичное описание инфраструктуры.
