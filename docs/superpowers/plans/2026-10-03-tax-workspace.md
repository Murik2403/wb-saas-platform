# Налоговый подраздел Finance — план реализации

**Goal:** Шесть режимов расчёта по подтверждённым данным, сверка начислений и оплаты, история и CSV в отдельном подразделе Финансов.
**Architecture:** Decimal-движок tax_calculator.py; существующий shop-local журнал сохраняет версии и совместимость АУСН. React-панель разделяет ввод, результат и историю. Старый автоматический расчёт из реализации WB остаётся за accountant gate.
**Tech Stack:** Python/SQLite/FastAPI, React/TypeScript/Vitest.
**Spec:** Задание пользователя от 2026-10-03; источники ФНС в docs/TAX_WORKSPACE_RULES_2026-10-03.md.

## Ограничения
- Пустое значение не равно нулю. Все обязательные суммы вводятся явно.
- УСН/ОСНО: данные с начала года; АУСН: календарный месяц. Исторические записи АУСН не изменяются.
- УСН минимум 1% только итог декабря; АУСН расходы минимум 3% месяца.
- Входящий НДС только общий режим НДС; 5/7% без вычета. Данные без НДС, исходящий НДС отдельный.
- Записи owner/manager, изоляция магазинов, оптимистическая блокировка, CSV без формул.
- Не менять P&L/ЕНС автоматически и не отправлять данные в ФНС.
- Тенанты demo/mvvorokov: только закоммиченный HEAD, encrypted backup и rollback, память 1536MiB.
