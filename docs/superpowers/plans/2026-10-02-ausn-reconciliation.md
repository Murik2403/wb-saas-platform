# АУСН: сверка по месяцам

**Goal:** отдельная оценка АУСН «Доходы» 8% по подтверждённым пользователем поступлениям и взаимозачётам, с начислением ФНС, оплатой и историей.

**Architecture:** новый ручной журнал по календарному месяцу в БД выбранного магазина. Он не включает непроверенный автоматический УСН-калькулятор и не изменяет существующий P&L. Финансовый результат до налога вводится отдельно для сценарной оценки после налога; платёж не вычитается второй раз.

**Sources:** https://ausn.nalog.gov.ru/ ; https://www.nalog.gov.ru/rn39/ifns/imns39_08/events/16638875/

## Ограничения
- Доходы месяца: поступления + удержанный взаимозачёт + отдельно не включённые компенсации + прочие доходы − возвраты. Пользователь сверяет даты и отсутствие двойного учёта по документам; продажи WB не признаются налоговой базой автоматически.
- АУСН «Доходы» 8%, период календарный месяц. Не рассчитывать ОСНО, входящий НДС или АУСН «Доходы−Расходы» без полной модели.
- Поля без данных остаются null, подтверждённый ноль вводится явно. Сохранение требует основания и подтверждения состава базы.
- История неизменяемая, текущая запись защищена revision от потери параллельных изменений. Никаких запросов к WB или ФНС на запись.
- Собрать только закоммиченный HEAD, выкатить demo и mvvorokov с 1536 MiB после encrypted backup и live-проверок.
