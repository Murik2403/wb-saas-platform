# Публичная карта возможностей

Цель: закрыть требование расширенного аудита о привязке задачи к экрану, источнику данных, ручному вводу и ограничениям. Публичные описания выпускаются после соответствующего tenant-релиза.

1. Добавить `/capabilities` с фактическими контурами и явно ограниченным учётом Ozon, дополнительных магазинов и ДДС.
2. Отразить в тарифе реальные пределы: пять дополнительных рабочих областей включая отключённые, 128 МиБ на историю дополнительного магазина, глубину запросов WB и Ozon. Не обещать бессрочную доступность API или неограниченную нагрузку.
3. Включить страницу в sitemap и проверить публичные SEO/маршруты. Сохранить действующий favicon из исходного принятого SEO-коммита `b963a88`.
4. Независимая проверка формулировок, сборка gateway, зашифрованная резервная копия control-plane, изолированная проверка и живые проверки после переключения.
