# Светлая тема кабинета и главной

Goal: дать посетителю и владельцу кабинета выбор светлой и тёмной темы с сохранением предпочтения.

Architecture: раннее применение `data-theme` до отрисовки, общий ключ `marketshelper-theme` в localStorage каждого origin, доступная кнопка в навигации. Семантические цвета сохраняют отдельные палитры кабинета и публичного сайта.

Tech stack: React, TypeScript, CSS variables, Jinja, plain JavaScript. Без новых зависимостей.

Global constraints: тёмная тема по умолчанию; блокировка localStorage не ломает переключатель; финансовые данные и настройки магазинов не изменяются; чужие файлы не включать в коммиты; выкатывать только закоммиченный HEAD.
