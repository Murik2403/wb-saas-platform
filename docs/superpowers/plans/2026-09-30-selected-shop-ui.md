# Selected-shop frontend acceptance plan

Base1f6f00f; frontend only, backend contract supplied by shared builder. Read session shops/role/route scopes before authenticated screen requests. Unknown session/unknown shop/unauthorized or inactive shop fails closed; never primary fallback. Tenant-shared inventory/production/cash explicitly labelled and accessible only by supported route contract.

Central scoped transport wraps all tenant API fetches, stamps selected shop/revision, rejects unsupported secondary paths/actions, aborts outstanding requests on switch and discards stale responses even when transport ignores AbortSignal. Scope-keyed remount clears form previews, stale plans, replay keys and asynchronous effects. Mutation request identity is UUID, scope/revision bound, never copied to another store; do not claim a blocked or unsupported operation succeeded. Validate secondary response identity/revision/fingerprint where required by backend. Preserve primary backward-compatible business semantics and no duplicate physical stock.

Tests: strict session validation; unknown shop rejection; abort+late-response isolation; scoped headers and malformed/mismatched secondary identity; read-only/unknown mutation rejection; stable request UUID exact retry vs changed payload; accessible selector and failure/retry bootstrap; full React suite and production build. Independent source acceptance before root integration; no independent deploy.


Refined contract: route_scopes is an array of method/path/template/scope plus per-route can_write/action; allowed_actions exact METHOD template. Identity/fingerprint64hex; primary identity/revision nullable, secondary revision integer including0. Unknownprimary legacy paths remain permitted per backend explicit backwardcompatibility; unknownsecondary rejected. Secondary current response revision may advance after write/replay, never regress.

Both manual shop switch and newer revision invalidate context and perform full document navigation with preserved period/view. This intentionally disposes legacy multi-step async handlers; keyed React remount alone cannot stop an old callback initiating a later mutation against the new shop. Until fresh bootstrap, all transport access is denied. Multipart/binary bodies use fresh keys because a file content identity is not proven; no JSON.stringify(FormData)=={} replay sharing. Headers for response clones and asynchronous body decoding remain scope-guarded. Direct finance links now download through guarded blob transport.
