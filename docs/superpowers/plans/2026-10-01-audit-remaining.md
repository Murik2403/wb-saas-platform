# Остатки общего аудита — план завершения

**Основание:** FULL_PRODUCT_MARKET_AUDIT_2026-09-23.md, PRODUCT_AUDIT_2026-09-23.md, AUDIT_REQUIREMENT_RECONCILIATION_2026-09-30.md и CABINET_UX_AUDIT_2026-09-30.md.

**Цель:** закрыть подтверждаемую программную работу и приёмку, сохраняя открытыми требования, для которых нет реальных внешних свидетельств.

**База:** codex/cabinet-ux-20260930, 93714b5. Изолированные рабочие деревья; основная копия Claude не используется для выпуска. Клиентские данные и права не меняются при проверках; тестовые записи только в локальных учебных базах.

- [ ] Независимый агент сверяет все требования с кодом и текущими доказательствами. Результат: точный реестр остатков, без повторного выполнения уже принятых пунктов.
- [ ] Агент Ozon проверяет первичный денежный контракт и реализует нормализацию только при достаточных источниках. Preview/confirm, дедупликация, знаки/валюты, полнота и возвраты проверяются независимо; реальные данные отсутствуют и не объявляются проверенными.
- [ ] Агент учебного курса создаёт и проверяет недостающие уроки всех 11 разделов. Только актуальные экраны с вымышленными данными, полный рендер и проверка кадров; обзор не подменяет курс.
- [ ] Root проверяет неопределённый ответ и повтор UUID в браузере, мобильные заполненные таблицы и диалоги на локальных учебных базах.
- [ ] Каждый обнаруженный дефект получает воспроизводящий тест и ограниченную правку. Root интегрирует проверенные коммиты и запускает полный релизный gate на чистом архиве HEAD.
- [ ] Root выпускает изменения кабинета в demo/mvvorokov с восстановленной зашифрованной копией, лимитом 1536 MiB и сохранением rollback. Traefik не пересоздаётся без необходимости; если потребуется, только штатным traefik_up.sh.
- [ ] Обновляется реестр закрытия: ревизии, проверки, доступные материалы и внешние зависимости (исторические документы/Ozon, интервью, реальный кейс и когорта). Весь аудит закрывается только при наличии свидетельств по каждому обязательному пункту.
