# Чек-лист ручной приёмки MARKETSHELPER

Дата подготовки: 18.09.2026

Этот список предназначен для финального прогона на тестовом tenant после выкладки. Непроверенные пункты не считаются закрытыми по результатам автоматических тестов.

## Перед началом

- [ ] Открыт новый redesign tenant, не Streamlit
- [ ] Выполнен вход owner/manager/viewer; проверены права ролей
- [ ] Подключён тестовый WB-токен с нужными категориями
- [ ] Для уведомлений настроены SMTP и Telegram-бот
- [ ] Создана резервная копия tenant перед write-сценариями

## Производство

- [ ] Карточка производства открывается кликом и клавишей Enter
- [ ] Норма материала редактируется и сохраняется
- [ ] Фактическое количество и примечание сохраняются
- [ ] «В работу» меняет статус задачи на «В работе»
- [ ] «Готово» доступно только после фактического завершения
- [ ] «Закрыть смену» завершает операцию и не зависает
- [ ] После обновления страницы статус и данные сохраняются

## Поставки и поставщики

- [ ] Открываются новые сборочные задания и FBS-поставки
- [ ] Карточка поставки открывается, QR/стикер запрашивается
- [ ] Внутри «Поставки» есть отдельный раздел «Поставщик»
- [ ] Создание/редактирование поставщика сохраняет контакты, телефон, Email, WeChat/Telegram
- [ ] Ошибка прав WB показывается причиной, а не пустыми нулями

## Отчёты

- [ ] Быстрый отчёт формируется за 1, 7, 30 и 90 дней
- [ ] День/неделя меняют данные графика и подписи периода
- [ ] Новое расписание открывается со всеми разделами отчёта отмеченными
- [ ] Ежедневное, еженедельное и ежемесячное расписания сохраняются
- [ ] История запусков показывает статус, ошибку и скачивание готового файла
- [ ] Email отображает фактический статус SMTP
- [ ] Telegram выдаёт код, открывает ссылку бота и после `/start` показывает привязку
- [ ] Тестовый отчёт реально доставляется на Email и в Telegram

## Настройки и аккаунт

- [ ] Подключение/отключение WB-токена не возвращает токен в ответе
- [ ] Карта прав токена и недостающие категории отображаются
- [ ] Onboarding нового tenant проходит от токена до первой синхронизации
- [ ] Смена пароля, email и выход из всех сессий работают
- [ ] В профиле доступны billing, account, offer, privacy и поддержка

## Мобильная версия

- [ ] Главная открывается на iOS/Android без горизонтального скролла
- [ ] Нижняя навигация не перекрывает карточки и кнопки
- [ ] Все карточки и действия доступны пальцем
- [ ] Модалки закрываются кнопкой, свайпом/системной кнопкой назад
- [ ] Производство, поставки и отчёты проверены в портретной ориентации
