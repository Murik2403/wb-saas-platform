# Новые обучающие видео — 3 октября 2026

Пять уроков продолжают существующий курс: номера 12–16, каждый 120 секунд, 1920×1080, 24 кадра/с. Формат — реальные кадры текущих React-компонентов с последовательными пояснениями и русскими WebVTT-субтитрами, без звуковой дорожки. Вкладки показаны внутри тематических уроков.

| Урок | Что показано |
| --- | --- |
| `lesson-12-tax` | Вкладка «Налоги», шесть доступных режимов, поля доходов/возвратов, НДС и подтверждение, начисление и оплата, раскрытая история, CSV |
| `lesson-13-product-analysis` | Тепловая карта, выбор метрики, CSV, РНП: план, факт, отклонения, простой прогноз и маржа |
| `lesson-14-ads-analytics` | CTR/CPC/CPM/CPO, конверсии и ДРР по рекламным заказам, сравнение, таблицы дней/кампаний и CSV |
| `lesson-15-fbs` | Сводка FBS, фильтры и два статуса заказа, оценка возраста/просрочек, права обновления, CSV текущей страницы |
| `lesson-16-self-buyouts` | Учёт уже совершённых операций, сводка, группировка, заполненная форма без отправки, журнал и CSV |

Данные полностью вымышлены. Использованы `WorkspaceTabs`, `TaxReconciliationPanel`, `ProductsHeatmap`, `RnpPlanFact`, `AdsAnalyticsPanel`, `FbsOrdersPanel`, `SelfBuyoutsPanel` из исходников кабинета на основе `52c0d1a`; картинки не являются скриншотами клиентского кабинета. Фикстура блокирует неизвестные обращения приложения и отвечает только локальными примерами. Уроки не подтверждают финансовую корректность вымышленных показателей или интеграции с WB.

Налоговый урок объясняет документальную оценку и сверку, без обещания автоматической загрузки всех расходов или подачи деклараций. Урок РНП не демонстрирует успешную запись плана и не обещает прогноз продаж. FBS не показывает денежную цену заказа: в текущем компоненте такой колонки нет. Урок самовыкупов посвящён учёту затрат, не организации покупок или отзывов.

Метаданные и сценарии: `NEW_LESSONS_2026-10-03.json`. Media, HyperFrames compositions, исходники локальной фикстуры, полные CUA-кадры, происхождение и доказательства находятся вне Git в каталоге `audit-private-deliverables-20260930/training-advanced-20261003` рядом с checkout. Для каждого урока подготовлены `video.mp4`, `poster.jpg`, `captions-ru.vtt`, `contact-sheet.jpg`, `MEDIA_PROOF.json` и редактируемый `index.html`.

## Повторное изготовление и проверка

1. `python scripts/build_advanced_training.py --output <outside-git-directory>` создаёт временную автономную учебную страницу и сохраняет её исходник в выходном каталоге. Запустите локальный Vite только на `127.0.0.1`.
2. Через CUA откройте локальную страницу, пройдите нужные состояния и сохраните screenshots. Для нижних форм используйте full-page screenshot и явный фрагмент; исходные координаты заносятся в `CAPTURE_FRAMING.json`. Не захватывайте реальные клиентские данные.
3. Подготовьте шесть `assets/step-N.png` (1920×680) для каждого урока. Запустите `python scripts/compose_advanced_training.py --output <outside-git-directory>`.
4. В каждом каталоге урока выполните `npx --yes hyperframes@0.8.113 check --json` и `npx --yes hyperframes@0.8.113 render --output video.mp4 --fps 24 --workers 2`. Сохраните check-отчёт в `check.json`.
5. `python scripts/verify_advanced_training.py --output <outside-git-directory>` полностью декодирует видео, проверяет параметры, создаёт постеры и шесть контрольных кадров на урок. После ручного просмотра повторите команду с `--visual-approved`; это единственный шаг, разрешающий `ready_verified`.
6. Остановите временный Vite и удалите сгенерированные `mh-redesign-lab/src/training-preview-private.tsx` и `mh-redesign-lab/training-preview-private.html` до коммита или сборки production.

`COURSE_READINESS_MANIFEST.json` содержит только пять новых уроков. При публикации объедините его с действующим manifest, сохранив все одиннадцать прежних видео. Сам факт рендера не означает публикацию: внешний release и живую проверку `/training` выполняет основной релизный процесс.
