## Правила учета и границы

- Выпуск сохраняет стоимость сырья FIFO, труда, упаковки, прочих затрат и износа оборудования. Недостаток любого компонента откатывает всю проводку. Повтор с тем же кодом не дублирует выпуск.
- При отсутствии фактической работы применяется расценка операции из BOM с признаком `bom_norm`. Амортизация — норма ресурса × выпуск, с ограничением общей амортизируемой стоимости. Это не телеметрия оборудования и не расчет зарплатных налогов.
- Отмена восстанавливает сырье и ресурс; использованную готовую партию отменить нельзя. История отмены сохраняется. Новый исправленный выпуск требует нового кода.
- Стоимость выпуска не списывается сразу в прибыль: непроданные изделия остаются запасом. Основной финансовый отчет пока использует стоимость товара из настроек. Нужна отдельная интеграция FIFO со строго сопоставленными продажами и возвратами WB; периоды продажи и реализации различаются. Ограничение показано в интерфейсе.
- Реализована первая фаза рекомендации BOM: несколько компонентов и версии на SKU (`nm_id`). Отдельная размерная матрица внутри одного `nm_id`, многоуровневые полуфабрикаты и закрытие финансовых периодов не реализованы и не заявляются.
- Календарь отображает сохраненные задания, а не автоматически оптимизирует расписание.
- Производственные роли ограничивают изменения; чтение данных кабинета общее, что прямо указано при приглашении. API-ключ ограничен отдельными маршрутами чтения и одним кабинетом.
- По указанию владельца сравнения/ссылки на 1С не возвращаются. Непроверенные рыночные утверждения из аудита не публикуются. Исключенные самим аудитом внешняя аналитика, РРЦ, антиконтрафакт и расширение браузера не добавлялись.

## Проверки

- Временная отдельная база: браузерный сценарий BOM из 2 м ткани по 12,50 ₽ и 0,1 кг нити по 125,50 ₽ на изделие. Выпуск трех изделий: 112,65 ₽; отмена восстановила остатки.
- Мобильная ширина 390 px: формы и журнал без выхода полей за экран, отмена доступна, после отмены кнопка заблокирована.
- API: 212 тестов; интерфейс: 50 тестов; учет/FIFO/НЗП: 65 тестов; gateway: 375 тестов и 146 подтестов. Все прошли. TypeScript и production-сборка прошли; остаются два предупреждения об устаревающих API зависимостей Python.
- На живом демо проверены новые формы: сохранение отключено, показан режим просмотра. Сервер также возвращает 403 на запись наблюдателем; демо возвращает `read_only=true`, `allowed_actions=[]`.
