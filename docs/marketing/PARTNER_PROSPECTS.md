Собрано 21.09.2026. Контакты взяты только со страниц «Контакты» и футеров
собственных сайтов компаний либо из их же ссылок на Telegram. Ни один адрес
не сконструирован по шаблону, никому не отправлено. С 25.09 компании и
черновики, где предложение опиралось на 1С, исключены из активного аутрича
по решению владельца. Список ниже сохраняет исторические заметки; это не
очередь контакта. Актуальные статусы адресатов — в [OUTREACH_STATUS.md](OUTREACH_STATUS.md).

**Почему 27, а не 500.** Больше в открытом доступе нет: остальное, что
выдаёт поиск, — либо крупные платформы с собственной бухгалтерией для
маркетплейсов (они не клиенты, а конкуренты), либо SEO-сайты без реальной
специализации. Список качественный, а не количественный: у каждого есть
конкретная зацепка из его собственных материалов.

## Правила работы со списком

1. Писать по 8–10 писем в день, не пачкой. Иначе это рассылка, и выглядит так же.
2. Открывать письмо зацепкой этого человека, а не описанием сервиса.
3. Перед отправкой открыть страницу «Контакты» глазами — особенно ЮКСОР
   (email частично замаскирован) и «Простые решения» (два написания домена).
4. Не обещать условий партнёрства: они не зафиксированы.
5. Ответ «не интересно» — закрывающий. Второе письмо не отправляется.

## Кому писать не надо

**Конкуренты с собственным продуктом учёта:** Оцифровка (mpnl.ru), iSeller,
MPFinAssist, ПланФакт, КУБ24, LiteStat, Soykasoft, TotalCRM, WildCRM,
Topseller. С ними возможно партнёрство, но не продажа.

**Крупные платформы:** Кнопка, Т-Банк Бухгалтерия, Точка, Моё Дело, Контур,
СБИС, СберРешения, Фингуру, 42clouds. Только интеграция, если вообще.

**Архивная заметка, не использовать для аутрича:** прежняя гипотеза
предлагала обратиться к интеграторам 1С с предложением «дополнение к 1С».
Эта гипотеза снята решением владельца. BINOM, Assistant1C, 1С-Victory,
1С:БухОбслуживание, Главбух Ассистент, а также связанные с 1С углы для
«Экспресс Бухгалтерии», «Учёта без забот» и Профдело исключены из активной очереди; подробности сохранены
в разделе снятых адресатов файла [OUTREACH_STATUS.md](OUTREACH_STATUS.md).

**КУБ2Б (qb2b.ru)** — зацепка есть, публичного контакта нет, только форма.
