# Кабинеты WB и Ozon — 7 октября 2026

Верхний переключатель площадки открывает отдельный кабинет WB или Ozon. Навигация и период сохраняются отдельно. В Ozon не монтируются запросы, KPI и формы WB. Переключение отменяет запросы и чтение отложенных ответов, очищает черновики. URL и localStorage не предоставляют права доступа.

## Фактическая поддержка Ozon

| Раздел | Доступно |
| --- | --- |
| Сегодня | Отправления и документальная выручка/результат с явной полнотой источников |
| Склад | Доступные/резервные единицы по текущему снимку Seller; исторический остаток не выдумывается |
| Товары | Экономика по SKU, тепловая карта, план/факт; цены, CSV, черновик, отдельное подтверждение отправки |
| Поставки | Просмотр FBO/FBS-отправлений и возвратов; исходные статусы |
| Реклама | Существующая аналитика через отдельный Performance API и его подключение |
| Финансы | Помесячный документальный ОПиУ, налоговые входные данные, сверка начислений, исторический FIFO, документы реализации, общие счета |
| Производство | Общая калькуляция производственных затрат; физический каталог пока использует WB-идентификаторы |
| Агенты | Ручной проверяемый процесс работы с ценами; автоматических правил ставок и бюджетов нет |
| Отчёты | Документальный ОПиУ и CSV |
| Контроль | Проверки наличия, актуальности и полноты источников |
| Настройки | Seller-ключи, загрузка периода, текущая стоимость SKU, отдельные разрешения команды |

Демо строго доступно для просмотра. Для реального кабинета требуется доверенная сессия шлюза. WB-разрешение сотрудника не открывает Ozon: владелец отдельно выдаёт доступ. Снимки и подтверждения цен привязаны к Seller Client-Id; старые снимки без подтверждённого продавца требуют новой загрузки. Ротация ключа того же Seller сохраняет источник. Документальная история не удаляется.

Цены читаются из локального снимка; внешняя загрузка вызывается явно. Подтверждение проверяет продавца, свежие цены и черновик, сохраняет журнал до единственной внешней отправки. Неопределённый ответ, 429 и частичный результат не объявляются полным успехом и не повторяются автоматически.

## Границы равенства площадок

Одинаковая навигация не означает полной идентичности операций. Создание поставок/сборка FBS/возврат денег Ozon, автоматическое управление рекламой и автоматическое сопоставление физического производства с SKU Ozon ещё не реализованы. Реальные финансовые результаты и отправка цен требуют последующей проверки на непустых данных и отдельного действия оператора; в приёмке внешних изменений не выполняем. Отсутствие себестоимости, документов или рекламы не означает подтверждённый ноль.

Контракты источников сверены с [официальной документацией Ozon Seller](https://docs.ozon.ru/api/seller/): FBS v4/FBO v3, страницы до 100 отправлений, курсор возвратов v1, товарные идентификаторы v3, цены v5 и import/prices v1. Клиент не подменяет SKU значением product_id и не преобразует Money в выручку.
