## Правило завершения

Для программного блока: независимый просмотр → meaningful tests → зашифрованная восстановленная копия → новый и rollback образ → production deploy → live UI/API → запись версии и оставшихся ограничений. Для интервью/кейса/видео: действительный материал и проверяемый результат. Планы, отдельные модули, синтетические примеры или работающие GET сами по себе не закрывают весь аудит.
