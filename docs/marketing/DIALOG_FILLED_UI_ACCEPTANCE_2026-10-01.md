# Диалоги и заполненные экраны — 1 октября 2026

Проверка выполнена на отдельной локальной базе с вымышленными данными. Клиентские базы, токены, цены маркетплейса и расходы владельца не менялись. Этот документ не утверждает, что каждый диалог вручную проверен на каждом устройстве.

## Исправления

- Общий `dialog-focus.ts` временно делает фон `inert`, возвращает ушедший фокус в верхний диалог и восстанавливает прежние атрибуты после закрытия. Вложенные/соседние scopes и закрытие родителя раньше ребёнка покрыты регрессией.
- Tab учитывает `summary` и редактируемые элементы, пропускает содержимое закрытого `details`, скрытые/disabled/inert элементы и явный отрицательный tabindex.
- Native `openInteractionDialog` удаляется перед возвратом фокуса. В настоящем браузере прежний порядок оставлял фокус на body: браузер не разрешал фокусировать кнопку вне ещё открытого native modal.

## Полный перечень scopes в App.tsx

Все 14 React scopes используют один hook `useDialogFocus`. Это проверка общей реализации, не 14 отдельных браузерных результатов.

| Диалог | Сценарий |
|---|---|
| MobileNavigationDialog | Все разделы мобильного меню |
| PlanDrawer | План задач, фильтры, детали и статусы |
| ActionDetailDialog | Детализация действия/партии |
| ProductCardEditor | Карточка WB, поля и медиа |
| DetailDrawer | Заполненная детализация товара/склада |
| FifoDialog | Диагностика и разрешённая локальная сверка |
| AgentDecisionDialog | Подтверждение решения агента |
| FbsSupplyDialog | Поставка FBS, QR/стикер |
| OperationDialog | Создание смены/операции |
| ProductCostDialog | Себестоимость товара |
| ProductionNormDialog | Норма материала |
| SupplierDialog | Поставщик |
| ProcurementPaymentDialog | Учёт оплаты закупки |
| ProcurementReceiptDialog | Приход сырья |

Дополнительно `openInteractionDialog` обслуживает native подтверждение, текстовый ввод и сообщение результата. Два `window.confirm` (отмена ДДС/удаление расхода) используют собственный диалог браузера.

## Границы результата

Общая клавиатурная реализация покрыта регрессией и репрезентативными настоящими browser checks. Запись во все перечисленные бизнес-сценарии, подключение реального WB/FBS, каждая платформа экранного диктора и фактическая речь диктора этим не проверены. Проверка речи не была отдельным исходным обязательным требованием аудита; её отсутствие не превращается в доказательство дефекта или блокирующий выпуск критерий.

Полный frontend gate после изменений: 297 тестов / 48 файлов; TypeScript/Vite прошли. Неблокирующее предупреждение Vite о размере JS chunk сохраняется. Root выполняет интеграционный gate и deployment.
