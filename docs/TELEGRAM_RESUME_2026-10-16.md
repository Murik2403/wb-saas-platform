# Возврат Telegram по решению владельца

16.10.2026 владелец прямо поручил вернуть Telegram на сайте. Переключатель `WB_SAAS_TELEGRAM_ENABLED=1` применяется к gateway, provisioner и существующим кабинетам. Новые кабинеты получают значение от provisioner. Compose явно передаёт переключатель обоим сервисам; локальный `.env` сам по себе не обеспечивает его передачу.

Это изменение конфигурации: образы, ключи, привязки чатов, роли, лимиты, тома и настройки расписаний сохраняются. Прежние контейнеры сохраняются для отката. Ссылки поддержки и интерфейс привязки возвращаются существующим кодом. Тестовая отправка сообщений клиентам не требуется.

Перед возобновлением проверены доступность Telegram API и отсутствие накопленных updates (0). Старые сообщения не удалялись и не подтверждались отдельным запросом с offset.

Регистрация уведомления РКН не используется как доказательство урегулирования всех вопросов внешних каналов; публичные юридические тексты в этой задаче не меняются.

Фактический результат включения записывается отдельно в акте оператора в deliveries/telegram-resume-20261016.
