# Google Play: Data safety (ответы по реальным данным)

Источник: https://marketshelper.ru/privacy (gateway/templates/privacy.html). Если политика изменится, пересмотрите этот файл.
Приложение является обёрткой над сайтом (WebView): сбор происходит на сервере MARKETSHELPER.

## Общие вопросы
| Вопрос | Ответ |
|---|---|
| Собирает ли приложение пользовательские данные? | Да |
| Шифруются ли данные при передаче? | Да (HTTPS/TLS, cleartext запрещён) |
| Можно ли запросить удаление данных? | Да: https://marketshelper.ru/delete-account (страница должна работать до публикации; в репозитории gateway её пока нет, см. checklist.md) |
| Передаются ли данные третьим лицам? | Только обработчикам из политики: ЮKassa (платежи на сайте), хостинг Timeweb, почтовые сервисы. Продажи данных нет |
| Families Policy | Не применимо (аудитория 18+) |

## Типы данных
| Категория Google | Что именно | Собирается | Передаётся | Обязательно | Цель |
|---|---|---|---|---|---|
| Личная информация: адрес эл. почты | email аккаунта | Да | Нет* | Да | Функциональность, управление аккаунтом, связь |
| Личная информация: идентификаторы пользователя | внутренний ID аккаунта; Telegram ID (необязательно, для уведомлений) | Да | Нет* | ID да, Telegram нет | Функциональность, аккаунт |
| Финансовая информация: платёжная информация | НЕ собираем: карты обрабатывает ЮKassa на сайте | Нет | - | - | - |
| Финансовая информация: другая | статусы и даты оплат/подписки; данные кабинета продавца (выручка, расходы, себестоимость, остатки) из WB/Ozon и введённые пользователем | Да | Нет* | Да | Функциональность |
| Действия в приложении: другие действия | журнал действий в кабинете | Да | Нет | Да | Функциональность, безопасность |
| Данные приложения и производительность | IP, cookie-сессии, User-Agent, сбои | Да | Нет | Да | Безопасность, диагностика, аналитика |
| Идентификаторы устройства | push-токен FCM / RuStore Push (появится вместе с push) | Да, после включения push | Нет* | Нет (по согласию) | Уведомления |
| Секреты доступа | токены API WB/Ozon, хранятся зашифрованными | Да | Нет | Да (для интеграции) | Функциональность |

*Передача поставщикам-обработчикам, работающим от имени разработчика (хостинг, платёжный и почтовый сервисы), в Play не считается «передачей третьим лицам» при договорной обработке; уточните формулировку при подаче.

## Не собираются
Геолокация (точная и примерная), контакты, SMS и журнал звонков, фото и видео, аудио, файлы пользователя (разрешения камеры/микрофона/хранилища не запрашиваются), здоровье, сообщения, рекламные идентификаторы (AAID).

## Аналитика
Яндекс Метрика на сайте включается только после согласия пользователя (cookie-баннер); Вебвизор и карта кликов отключены. Если Метрика остаётся в WebView, отметьте «Данные приложения и производительность» как собираемые для «Аналитики».

## Дополнительно в Play Console
- Политика конфиденциальности: https://marketshelper.ru/privacy
- Удаление аккаунта: https://marketshelper.ru/delete-account; удаляются аккаунт и данные кабинета, записи, обязательные по закону (платежи), хранятся в законные сроки.
- Целевая аудитория 18+. Реклама в приложении: нет. Доступ к приложению ограничен логином (см. review-notes.md).
- Разрешения: INTERNET, POST_NOTIFICATIONS (Android 13+, запрашивается при включении push).
