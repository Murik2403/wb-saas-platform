# RuStore: требования и что приложить

Консоль: https://console.rustore.ru (аккаунт юрлица/ИП/самозанятого с подтверждением личности).

| Что | Значение |
|---|---|
| Пакет | `ru.marketshelper.app` (appId из `mobile/app.json`) |
| Формат | APK или AAB |
| Подпись | загрузите свой keystore (можно тот же, что для Play) в консоль; не теряйте, обновления подписываются тем же ключом |
| Иконка | 512x512 PNG (рендер из `mobile/assets/icon-only.png`) |
| Скриншоты | `mobile/store/screenshots/android/` (6 шт., 1080x1920; минимум 3) |
| Описания | короткое и полное из `listing-ru.md` |
| Политика конфиденциальности | https://marketshelper.ru/privacy |
| Возрастной рейтинг | по анкете RuStore (0+/3+) |
| Категория | Бизнес |
| Контакты поддержки | <SUPPORT_EMAIL> (укажет владелец) |
| Доступ для модерации | см. `review-notes.md` |
| Разработчик | реквизиты владельца (в политике указан ИП) |

## RuStore Push (опционально)
На устройствах без Google Mobile Services FCM не работает. Для них нужен SDK RuStore Push: `projectId` и сервисный ключ из консоли. В проект не добавлен, подключается отдельным нативным плагином (см. README, раздел Push).

## Возможные замечания модерации
- Обёртка над сайтом: поясните функциональность (кабинет селлера) и приложите тестовый доступ.
- Нужны актуальная политика и работающая страница удаления аккаунта.
- Платежей в приложении нет, подписка на сайте (ЮKassa).
