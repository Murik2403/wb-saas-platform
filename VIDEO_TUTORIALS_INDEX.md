## Рекомендуемый порядок публикации

Настройки → Контроль → Сегодня → Обзор → Финансы → Товары → Остатки → Закупки → Производство → Реклама → Агенты → Отчёты.

## Логика обучения

Пользователь сначала подключает источники данных, затем проверяет их качество, изучает текущую ситуацию, принимает финансовые и операционные решения и после этого настраивает автоматические рекомендации и отчётность.
