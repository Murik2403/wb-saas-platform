Тарифы

Учёт себестоимости, FIFO, производство и остатки для продавцов Wildberries.

Что входит

MARKETSHELPER — веб-сервис (личный кабинет в браузере) для продавцов на Wildberries: расчёт себестоимости методом FIFO по сырью и готовой продукции, учёт производства, сверка остатков между складом WB и внутренним учётом, финансовые отчёты. Для каждого клиента создаётся отдельный tenant-кабинет; данные разных продавцов разделены в сервисе.

Как это работает

  1. Регистрируетесь по email и подтверждаете адрес — карта не требуется.
  2. После подготовки кабинета начинается {{ trial_days }}-дневный пробный доступ.
  3. Когда пробный период заканчивается, для продолжения работы оформляется подписка — доступ к оплаченному кабинету открывается автоматически сразу после успешной оплаты.
  4. Отменить подписку можно в любой момент из личного кабинета, без обращения в поддержку.
