Тарифы

Учёт себестоимости, FIFO, производство и остатки для продавцов Wildberries.

Что входит

WB Control — веб-сервис (личный кабинет в браузере) для продавцов на Wildberries: расчёт себестоимости методом FIFO по сырью и готовой продукции, учёт производства, сверка остатков между складом WB и внутренним учётом, финансовые отчёты. Для каждого клиента поднимается отдельный, изолированный от других клиентов экземпляр сервиса — данные разных продавцов физически не пересекаются.

Как это работает

  1. Регистрируетесь по email — сразу открывается {{ trial_days }}-дневный пробный доступ, карта не требуется.
  2. Личный кабинет доступен сразу после регистрации, обычно в течение минуты.
  3. Когда пробный период заканчивается, для продолжения работы оформляется подписка — доступ к оплаченному кабинету открывается автоматически сразу после успешной оплаты.
  4. Отменить подписку можно в любой момент из личного кабинета, без обращения в поддержку.
