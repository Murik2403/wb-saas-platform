Что входит

MARKETSHELPER — веб-сервис (личный кабинет в браузере) для продавцов на Wildberries: расчёт себестоимости методом FIFO по сырью и готовой продукции, учёт производства, сверка остатков между складом WB и внутренним учётом, финансовые отчёты. Для каждого клиента создаётся отдельный tenant-кабинет; данные разных продавцов разделены в сервисе.

Как это работает

Пределы использования

Один основной WB-магазин и до пяти дополнительных финансовых рабочих областей WB на кабинет, включая отключённые. Отключение сохраняет данные и не освобождает место для нового магазина. История дополнительного магазина имеет технический предел 128 МиБ.

Участники работают в одном кабинете с назначенными ролями. Отдельный тариф за участника и отдельный числовой лимит участников не установлены; это не обещание неограниченной нагрузки.

Начальная загрузка WB настраивается от 7 до 90 дней; отдельная загрузка истории поддерживает до 365 дней при доступности данных API. Это глубина запроса, а не гарантия наличия всех операций. Данные сохраняются по фактически загруженным периодам. Ozon загружается отдельно, до 31 дня за запрос.

Экраны, источники данных и ручной ввод — проверьте свой сценарий до переноса всего ассортимента.

  1. Регистрируетесь по email и подтверждаете адрес — карта не требуется.
  2. После подготовки кабинета начинается {{ trial_days }}-дневный пробный доступ.
  3. Когда пробный период заканчивается, для продолжения работы оформляется подписка — доступ к оплаченному кабинету открывается автоматически сразу после успешной оплаты.
  4. Отменить подписку можно в любой момент из личного кабинета, без обращения в поддержку.
